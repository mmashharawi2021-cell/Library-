# مكتبة مهند — Web UI Reference

مرجع شخصي عربي RTL لأكثر عناصر تصميم الويب استخدامًا، مع معاينات تفاعلية ونسخ سريع للكود ومختبر تعديل مباشر.

## الخصائص
- 10 فئات رئيسية.
- معاينات حية ومكونات قابلة للتفاعل.
- بحث عربي/إنجليزي.
- HTML / CSS / JS / React / Tailwind.
- Playground مباشر.
- Favorites وRecent وCollections عبر LocalStorage.
- Responsive للحاسوب والهاتف.

المشروع Static ولا يحتاج إلى Build أو Dependencies.
