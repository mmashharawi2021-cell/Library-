# UI بالعربي

قاموس بصري عربي لعناصر واجهة المستخدم، مع معاينات تفاعلية، أسماء عربية/إنجليزية، رموز تنفيذ، مقارنات، وأنماط تصميم.

## حالة الإنتاج
- الإصدار المستقر: **V43**
- النشر: GitHub Pages
- السطح المفهرس: **122 URL**
- العناصر: **81** — Web: 49، macOS: 32
- الأنماط: **14**
- المقارنات: **18**
- جدول الترجمة: **63** مصطلحًا

## المرجع
يعيد هذا المشروع بناء تجربة عربية مستقلة مسترشدة بالبنية العامة وتجربة الاستخدام في [Name That UI](https://namethatui.com/). الكود، النصوص العربية، المعاينات والأصول في هذا المستودع أصلية وليست نسخًا من المصدر.

## التقنية
Static HTML/CSS/JavaScript، منشور مجانًا عبر GitHub Pages.

## البناء
```bash
node --check app.js
node scripts/build-static.mjs
```

يبني السكربت سطحًا ثابتًا داخل `dist/` مع Canonical وJSON-LD وSitemap. الصفحات الثابتة الملتزمة في المستودع يجب أن تبقى متزامنة مع نفس القالب حتى يكون مسارا GitHub Pages آمنين من نشر نسخة قديمة.

## اختبارات الإصدار
Workflow الإنتاج يتحقق من:
- صحة نموذج البيانات والتفاعلات الـ81.
- Reference Contract للمطابقة.
- الجوال واللمس على 393px.
- جميع روابط Sitemap الـ122.
- Canonical / robots / JSON-LD / manifest / RSS.
- عدم وجود ملفات أو حالات إصدار قديمة في السطح المنشور.
