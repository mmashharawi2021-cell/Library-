# UI بالعربي
قاموس بصري عربي لعناصر واجهة المستخدم.

## المرجع
يعيد هذا المشروع بناء تجربة عربية مستقلة مسترشدة بالبنية العامة وتجربة الاستخدام في [Name That UI](https://namethatui.com/). الكود، النصوص العربية، المعاينات والأصول في هذا المستودع أصلية وليست نسخًا من المصدر.

## التقنية
Static HTML/CSS/JavaScript، منشور مجانًا عبر GitHub Pages.
