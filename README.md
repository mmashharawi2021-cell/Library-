# UI بالعربي — ما اسم هذا العنصر؟

قاموس بصري عربي لعناصر واجهة المستخدم. يتضمن:

- 81 عنصر واجهة: 49 Web و32 macOS.
- 14 نمطًا بصريًا.
- 18 مقارنة للعناصر التي يكثر الخلط بينها.
- جدول ترجمة من 63 صفًا بين الاسم المرئي وAppKit وSwiftUI.
- بحث عربي/إنجليزي مع تطبيع الهمزات والتشكيل والياء والتاء المربوطة.
- صفحات تفصيلية: أسماء بديلة، التشريح، Prompt، Debug Prompt، In Code، عناصر مرتبطة.
- حفظ محلي، مشاركة، نسخ رابط، تعريف سريع بالنقر المزدوج، RSS.

## التشغيل

المشروع Static ولا يحتاج build. افتح `index.html` أو شغله بأي خادم ملفات ثابت.

## ملاحظة تحريرية

الكود والتصميم والنصوص العربية مكتوبة من الصفر. أسماء العناصر وواجهات API حقائق تقنية تُحفظ بصيغتها الصحيحة لتفادي إرباك المستخدم.
