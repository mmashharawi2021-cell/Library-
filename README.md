# مكتبة مهند — Web UI Reference

مرجع شخصي عربي RTL لعناصر تصميم الويب الأكثر استخدامًا.

## Library v2
- **70 نموذجًا** ضمن 10 فئات.
- **50 نموذجًا أساسيًا محسّنًا** للفئات: Buttons, Hover Effects, Cards, Inputs, Navigation.
- Schema موحّد لكل عنصر: `id / name / category / tags / code / complexity / favorite / usage`.
- بحث عربي/إنجليزي يفهم كلمات مثل: `glass`, `minimal`, `dark`, `animated`, `dashboard`, `hover`.
- فلترة حسب النمط ومستوى التعقيد.
- Playground مباشر لتعديل اللون والخلفية وRadius وPadding وحجم الخط والShadow والGlow والScale والسرعة.
- كود HTML/CSS يتحدث لحظيًا مع تعديلات Playground.
- Favorites وRecent وCollections وUsage عبر LocalStorage.
- تحسينات مخصصة للهاتف والـDrawer والـCode Panel.
- المشروع Static ولا يحتاج Build أو Dependencies.

## الفئات الأساسية الموسعة
كل فئة من الفئات الخمس الرئيسية تحتوي **10 نماذج منتقاة** بدل النماذج التجريبية القليلة السابقة.

## التحقق
تم اختبار البحث بالإنجليزية والعربية، فتح الـDrawer، تعديل Playground، تحديث كود CSS، إغلاق الـDrawer، والاستجابة للشاشات الصغيرة.
