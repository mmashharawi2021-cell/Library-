# UI بالعربي

قاموس بصري عربي لعناصر واجهة المستخدم، مع معاينات تفاعلية، بحث بالوصف، صفحة Explore، أسماء عربية/إنجليزية، رموز تنفيذ، مقارنات، وأنماط تصميم.

## حالة الإنتاج
- الإصدار: **V44 — Content Expansion & Discovery**
- العناصر: **101** = Core 81 + توسعة V44 (20)
- Web: **69**
- macOS: **32**
- الأنماط: **14**
- المقارنات: **18**
- جدول الترجمة: **63**
- السطح المفهرس: **143 URL**

## ما الجديد في V44
- 20 عنصر Web جديدًا غير موجودة في Core 81.
- صفحة `/explore/` للاكتشاف حسب المنصة والوظيفة ونوع التفاعل.
- بحث موسع يقرأ aliases وcalled phrases والتشريح والرموز التقنية ويستخدم مرادفات عربية/إنجليزية.
- بقاء Core 81 عقدًا مستقلًا للمقارنة مع Name That UI.

## المرجع
المشروع مستقل ومسترشد بالبنية العامة وتجربة الاستخدام في [Name That UI](https://namethatui.com/). الكود والنصوص العربية والمعاينات والأصول هنا أصلية.

## البناء
```bash
node --check app.js
node scripts/build-static.mjs
```
